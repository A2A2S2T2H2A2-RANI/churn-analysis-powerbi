# Customer Churn Analysis Dashboard (Power BI)

## 📊 Project Overview
This project analyzes customer churn behavior using Power BI. The dashboard focuses on engagement score, product usage, and customer segmentation to identify high-risk customers and improve retention strategies.

---

## 🎯 Objectives
- Analyze relationship between engagement and churn  
- Measure impact of product usage on retention  
- Identify high-value but disengaged customers  

---

## 🧠 Methodology
- Created calculated columns using DAX:
  - Engagement Score  
  - Customer Segmentation  
- Built KPIs:
  - Churn Rate  
  - Retention Rate  
  - At Risk Customers  
- Designed interactive dashboard using Power BI visuals  

---

## 📈 Key Insights
- Customers with low engagement have higher churn rates  
- Higher number of products leads to better retention  
- Inactive customers with high balance are at high risk  

---

## 🛠 Tools Used
- Power BI  
- DAX  
- Excel / CSV dataset
